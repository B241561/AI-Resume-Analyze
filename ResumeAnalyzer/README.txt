AI Resume Analyzer - Portable Windows App

How to run:
1. Extract the ZIP file.
2. Open the ResumeAnalyzer_Portable folder.
3. Double-click ResumeAnalyzer.exe.

No Python installation, Node.js, browser, command prompt, PowerShell, or local server is required.

Optional Gemini setup:
1. Copy .env.example to .env in this same folder.
2. Add your Gemini API key:
   GEMINI_API_KEY=your_gemini_api_key_here

If Gemini is unavailable or no API key is configured, the app uses the built-in keyword-based analyzer for demonstrations.

Reports are saved in the reports folder.
Temporary files can be stored in the temp folder.
